# SSAFY 임베디드 트랙 회로도

교육생용 회로도 페이지(GitHub Pages): https://hoconoco.github.io/ssafy-embedded-schematics/

- 이 repo는 배포용이다. 원본은 비공개 repo `trans_html`(`scripts/circuit/build_deck.py`)이 만들고, 회로·부품명 정본은 `ssafy_embedded_kit`이다 — 여기서 직접 고치지 않는다.
- 덱은 `index.html`(옛 주소 `SSAFY_embedded_track_schematics.html`은 장 주소를 유지한 채 첫 페이지로 넘김). 장 바로가기: 주소 끝에 `#<과목명>_Day<N>_p<쪽>` (예: `#라즈베리파이와AI_Day1_p78`)
